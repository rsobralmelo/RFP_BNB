# RFP 2026-013 — Explicada

Site estático, independente e não oficial, explicando a **RFP 2026-013** do Banco do Nordeste do Brasil S.A. — contratação de serviços técnicos especializados de apoio à gestão, operacionalização e distribuição de fundos de investimento (subsidiária BNB Asset).

O conteúdo foi compilado a partir dos 11 documentos públicos da RFP (Termo de Referência e Anexos I, II, III, V, VI, VII, VIII, IX, X, além das publicações no Diário Oficial da União), disponíveis na página oficial:

https://www.bnb.gov.br/acesso-a-informacao/licitacoes-e-contratos/consultas-e-audiencias

## Publicado com GitHub Pages

Este repositório é servido diretamente pelo GitHub Pages a partir da branch `main`. O site é um único arquivo (`index.html`), sem dependências de build.

## Aviso

Este é um resumo independente, sem qualquer vínculo com o Banco do Nordeste. Em caso de divergência, prevalecem os documentos oficiais linkados no próprio site.
